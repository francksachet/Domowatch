# Getting Started with DomoWatch

Welcome! This guide will help you get DomoWatch up and running.

First, identify which path applies to you:

---

## 🟢 Path A — I have a pre-assembled DomoWatch device

Your device comes with DomoWatch already installed and configured.
You just need to connect it to your WiFi and set up your home automation shortcuts.

**→ Skip directly to the [User Guide](user-guide.md)**

---

## 🔵 Path B — I have the Waveshare hardware and want to install DomoWatch myself

You purchased a **Waveshare ESP32-S3-Touch-LCD-1.69** board and want to install
the DomoWatch firmware on it.

**→ Follow the [DIY Installation Guide](diy-install.md)**

After installation, continue with the **[User Guide](user-guide.md)**.

---

## 🛒 I don't have the hardware yet

DomoWatch runs on the **Waveshare ESP32-S3-Touch-LCD-1.69** board.

You can find it at:
- [Waveshare official store](https://www.waveshare.com/esp32-s3-touch-lcd-1.69.htm)
- Amazon, AliExpress, and other electronics retailers

Once you have the board, follow the **[DIY Installation Guide](diy-install.md)**.

---

## What you'll need (all paths)

- A **2.4 GHz WiFi network** (WPA2) — DomoWatch does not support 5 GHz
- A **browser-equipped device** (phone, tablet, PC) on the same network, for initial configuration
- Optionally: a **home automation system** with HTTP support (Home Assistant, Jeedom, Node-RED, etc.)
